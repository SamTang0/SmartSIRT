# 🛡️ SmartSIRT

基于多智能体协作的安全事件协同响应系统

---

## 要解决的核心问题

### 1. 告警疲劳
安全设备每天产生数千条告警，误报率高，真实威胁被淹没在海量告警中，安全分析师疲于应对。

### 2. 响应割裂
- 研判需要登录 EDR 平台
- 查情报需要切换威胁情报系统
- 处置又要去防火墙或主机管理系统
- 一个事件需要多个平台来回切换，效率极低

### 3. 经验流失
- 资深专家的处置经验无法固化
- 新人上手需要大量时间学习
- 同样类型的告警，不同人处置标准不一致

---

## 解决方案

通过**多智能体协作**，实现告警处理的自动化闭环：

| 阶段 | 传统方式 | SmartSIRT |
|------|----------|-----------|
| 研判 | 人工分析告警内容 | 分析智能体自动研判 |
| 查情报 | 手动复制 IoC 到情报平台 | 情报智能体自动查询 |
| 决策 | 依赖个人经验判断 | 决策智能体给出标准化建议 |
| 处置 | 登录多个平台操作 | 输出可直接执行的处置动作 |

---

## 一句话总结

**让机器自动完成告警研判、情报查询、风险评估、处置建议的全流程，安全专家只需要处理机器无法判断的复杂事件。**
