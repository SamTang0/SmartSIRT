# SmartSIRT 产品方案文档

## 一、背景与问题

甲方安全运营中普遍存在三大痛点：

| 痛点 | 描述 |
|------|------|
| 告警疲劳 | 每日数千条告警，高误报率导致关键事件被淹没 |
| 响应割裂 | 研判→查情报→处置，跨多个平台，效率低 |
| 经验流失 | 专家处置经验无法沉淀，新人上手慢 |

## 二、MVP范围

- **场景**：挖矿告警（xmrig.exe）
- **智能体数量**：2个（分析智能体、情报智能体）
- **后续扩展**：勒索软件、钓鱼邮件、C2通信

## 三、智能体职责

| 智能体 | 职责 | 输入 | 输出 |
|--------|------|------|------|
| 分析智能体 | 告警研判、特征识别、提取IoC | 原始告警 | 结构化情报请求 |
| 情报智能体 | 威胁情报查询、风险定级 | IoC | 风险等级+处置动作 |
| 决策智能体 | 综合决策、生成建议 | 分析+情报结果 | 最终处置方案 |
