# SmartSIRT 接口文档

## 分析智能体

### 输入
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| alert_text | string | 是 | 原始告警文本 |
| hostname | string | 是 | 主机名 |
| username | string | 否 | 用户名 |

### 输出
| 字段 | 类型 | 说明 |
|------|------|------|
| ioc_type | string | domain/ip/hash |
| ioc_value | string | IoC值 |
| risk_level | string | high/medium/low |

## 情报智能体

### 输入
| 字段 | 类型 | 说明 |
|------|------|------|
| ioc_type | string | IoC类型 |
| ioc_value | string | IoC值 |

### 输出
| 字段 | 类型 | 说明 |
|------|------|------|
| risk_level | string | high/medium/low |
| threat_type | string | mining/c2/ransomware |
| confidence | float | 0-1之间的置信度 |

## 决策智能体

### 输出
| 字段 | 类型 | 说明 |
|------|------|------|
| final_risk | string | 最终风险等级 |
| action | string | 处置动作 |
| suggestions | list | 具体建议列表 |

## 调用时序

1. 调用分析智能体，传入原始告警
2. 获取IoC后调用情报智能体
3. 调用决策智能体，综合生成处置建议

## 错误处理

任一智能体超时或失败，降级为人工研判
